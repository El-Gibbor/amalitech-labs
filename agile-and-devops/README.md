# Agile and DevOps

An individual Agile and DevOps assessment run as two Scrum-style sprints, covering backlog refinement, sprint planning, CI, and sprint reviews and retrospectives.

The product built during the assessment is TaskFlow API, a small Spring Boot REST API for tracking the lifecycle of tasks. It lives in [`taskflow-api/`](taskflow-api/). See its [README](taskflow-api/README.md) for requirements, running, and testing.

Backlog, sprint plans, and sprint reviews and retrospectives are in [`docs/`](docs/).
